# 音声からピッチ転写

開発版の「一括編集 → 自動調声 → 音声からピッチ転写…」で、音声ファイルのピッチを既存ノートのカーブへ取り込めます。公開ZIPのone-click.8には未収録です。

1. 転写先のノートを選択します。未選択なら、そのパートの全ノートが対象です。
2. メニューから単独の歌声・話し声を録音した音声を選びます。WAV・MP3・OGG・Opus・FLAC・M4Aに対応します。
3. 「音声0秒の配置先」を、選択先頭のノートか曲の0秒から選びます。「位置の補正」は正の値で音声を後ろへ、負の値で前へずらします。
4. 解析方式と点数削減を選び、「ピッチを転写」を押します。⌘Zで戻せます。

音高・長さ・歌詞・ノート音量は保持し、ノートの基礎ピッチカーブを置き換えます。歌唱テクニック・ビブラート・PITDの既存設定も保持するため、これらによる変化は転写結果に重なります。有声音を検出できなかったノートは変更しません。伴奏と歌声が混ざった音源からの歌声分離や、歌詞・ノートの自動生成は行いません。

## 再利用した処理と公式の既存機能

解析には、OpenUtauがすでに同梱する`Worldline.F0`のpYIN／WORLD DIO＋StoneMaskを使用します。音声の読み込み・モノラル化・16kHzへの変換は既存のWave／NAudio、点数削減・歌唱テクニック再適用・Undoも既存処理を使います。解析エンジンの新規実装、Rosetta、Python、新しいモデルのダウンロードは不要です。新規部分はファイル選択・位置合わせ・ノート座標への変換とメニューです。

OpenUtau 0.1.576には、これとは別に音声リージョンから採譜するSOME／GAMEと、音声リージョンのピッチを既存の歌声パートへ適用するRMVPEもあります。これらは追加の解析モデルが必要です。音声の右クリックにある「オーディオを解析して音符に変換」、歌声パートの右クリックにある「Apply pitch from…」が元々の入口です。RMVPEはPITDへ書き込み、今回の入口はノートの制御点へ書き込みます。

参照元は[公式0.1.576のピッチ解析](https://github.com/stakira/OpenUtau/blob/bc194b6fe4897427a73066390b286e11205fd10f/OpenUtau.Core/Analysis/Rmvpe.cs)と[同梱解析処理](https://github.com/stakira/OpenUtau/blob/bc194b6fe4897427a73066390b286e11205fd10f/OpenUtau.Core/Render/Worldline.cs)です。

Wave2SeqはWindows向けの別製品です。配布物の利用条件が本体・改変版の同梱再配布を禁止しているため、本機能にはWave2Seqの実行ファイル・コード・素材を使用していません。

## 検証状況

ARM64で、ピッチの単位・位置変換、無声区間、44.1kHzステレオ音声の切り出しと解析、キャンセル、既存の自動調声を合わせた15件の試験に合格しました。既知の220Hzを、読み込み経路を含めてpYIN／DIOで確認しています。再生音は出していません。

実画面ではアプリの起動と検証譜面の表示まで確認しています。操作ツールで自動調声のサブメニューを展開できず、ファイル選択から転写・Undoまでの実画面試験、実録音での転写品質評価は未完了です。
